ARGUE WITH THE LETTER OF THE TASK (do this BEFORE listing steps):
The literal task is: "{{TASK}}". In one sentence, state the REAL underlying goal.
Then ask: does executing the task literally actually serve that goal, or could it harm it?
If the literal instruction is a poor path to the goal, DO NOT plan to execute it blindly.
Propose a better path Z, justify it in 2-3 lines, and put it under a heading exactly
"## PROPOSED REDIRECTION" so it is logged to DECISIONS.md for the owner's review. Do NOT
silently rewrite an explicit scope at night — flag it. If literal == best path, say so in
one line and proceed.

Canonical example: task "find an SEO skill and stamp out 100 articles" — the real goal is
organic traffic and qualified clients, NOT article count. 100 near-duplicate pages get
deindexed by Google and can hurt the domain. Path Z: a smaller set of genuinely useful,
differentiated pages targeting real search intent, plus distribution. Reorient to the goal;
never mass-produce slop to satisfy the letter.
