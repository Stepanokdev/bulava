---
description: Керування нічною зміною супервізора — start / stop / status / attach (per-project)
argument-hint: "[start|stop|status|attach|list] [шлях проєкту]"
---

Користувач керує нічною зміною (Codex наглядає за Claude). Кожен проєкт — окремий
інстанс зі своєю tmux-сесією `night-<slug>`, watchdog і git-гілкою; проєкти можуть
працювати паралельно. Аргумент: $ARGUMENTS

Розбери намір і виконай через команду `night-shift` (встановлюється в PATH через `~/.local/bin`):

- «start», «запусти» (+ опційно шлях) → `night-shift start "<шлях або $PWD>"`,
  потім підкажи підключення командою, яку виведе скрипт: `night-shift attach "<шлях>"`
  (вона сама знайде потрібну сесію `night-<slug>` — НЕ хардкодь `tmux attach -t night`).
- «stop», «стоп» (+ опційно шлях) → `night-shift stop "<шлях або $PWD>"`; для всіх проєктів — `night-shift stop --all`.
- «status», «статус», порожньо → `night-shift status` (покаже всі активні проєкти + здоров'я).
- «attach», «підключись» → `night-shift attach "<шлях або $PWD>"`.
- «list» → `night-shift list`.

Після виконання коротко звітуй стан. ВАЖЛИВО: якщо вмикаєш — нагадай, що поки інстанс
активний, Codex відповідає на питання замість користувача в цьому проєкті, тож не забути
`stop` (є й автозахист — залежалий інстанс гасне через 10 годин).
